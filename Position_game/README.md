# Simple Python Position Game

This is a beginner-friendly Python mini-project created as practice while learning Python.

##  How the Game Works
- You start with a list: `[0, 1, 2]`
- You choose a position (0, 1, or 2)
- You enter a new value to replace at that position
- You can continue editing the list as long as you choose “Y”

##  Concepts Used
- Functions in Python
- Lists and indexing
- Input validation using loops
- While loops and user interaction
